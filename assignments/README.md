# Домашние контрольные работы (ДКР)

---

## Общая информация

В этой папке находятся материалы для **домашних контрольных работ**.

Каждая ДКР содержит:
- 5 вариантов заданий
- Требования к оформлению
- Сроки сдачи

---

## Как выполнять ДКР

1. Получить вариант у преподавателя.
2. Ознакомиться с заданием.
3. Написать программу на PascalABC.NET и Python.
4. Оформить отчёт по шаблону `templates/dkr-report-template.md`.
5. Сдать работу преподавателю.
