## Как выполнять лабораторную работу

1. Прочитать задание в `task.md`.
2. Изучить примеры в папке `examples/`.
3. Написать программу на PascalABC.NET и Python.
4. Оформить отчёт по шаблону.
5. Сдать преподавателю.
